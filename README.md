#  Frontend -Gestion de Produits avec React

##  Description

Ce projet constitue le front-end d'une application web de gestion de produits, développé avec React. Il offre une interface utilisateur pour gérer l'inscription, la connexion, et l'interaction avec les catégories et les produits via des appels API au back-end Express.  


---


##  Technologies

- React
- React Router pour la gestion de la navigation
- Axios pour les appels API
- CSS pour le style et la mise en page
- LocalStorage pour la gestion du token d'authentification



---

##  Fonctionnalités

-  Authentification (Inscription / Connexion)
-  CRUD Produits
-  CRUD Catégories
-  Routes protégées avec token JWT
